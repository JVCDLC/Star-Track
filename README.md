## 🚀 Overview

**Star-Track** is an open-source project designed to transform a **manual telescope** into a fully **automated tracking system**.

It enables you to:
- 🔭 Automatically locate stars and planets  
- 🎯 Precisely orient the telescope  
- 🔄 Track celestial objects in real time  
- 🔍 Adjust focus dynamically  

The goal is simple: make astronomical observation **faster, easier, and more accessible**.
